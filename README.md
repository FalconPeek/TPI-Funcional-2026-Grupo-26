# Sistema de Semáforos Inteligentes y Análisis Comparativo de Paradigmas

Este repositorio contiene el desarrollo del **Trabajo Práctico Integrador 2026 del grupo 26** para la cátedra de Paradigmas de Programación. El proyecto consiste en el diseño e implementación del núcleo lógico para un sistema de control urbano de tráfico, desarrollado bajo el paradigma funcional estricto.
